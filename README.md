# Gravity Flip

Jeu 2D mélange Subway Surfers / Geometry Dash : un carré, deux plateformes, un tap pour inverser la gravité.

- 12 mondes, 15 à 30 niveaux par monde (270 niveaux), difficulté croissante
- Pièces (skins de personnages) et gemmes (thèmes)
- Pièges : piques, blocs, scies, scies roulantes, piques rétractables, jets de feu, lasers
- Traînée, animation du carré, musique chill générée
- Achats intégrés en mode démo (aucun vrai paiement)

Le jeu est dans `www/index.html`. L'APK est construit automatiquement par GitHub Actions (onglet Actions).
